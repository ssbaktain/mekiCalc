============================================================
 MekiCalc - 메이플 키우기 스탯 효율 계산기
============================================================

내 스탯과 큐브 옵션을 넣으면, 어떤 옵션이 딜을 얼마나 올리는지,
어느 부위를 먼저 굴리는 게 이득인지를 계산해 주는 도구입니다.
made by 탱구링 · 현재 베타 버전입니다.

(표시되는 값은 참고용이며 실제 게임과 정확히 일치하지 않을 수 있습니다.)

이 설명서는 처음 켜서 추천을 받기까지의 순서대로 정리되어 있습니다.
위에서부터 따라오시면 됩니다.


------------------------------------------------------------
 1. 실행 방법
------------------------------------------------------------

 1) 배포된 압축 파일을 풉니다.
 2) 폴더 안의 MekiCalc.exe 를 실행합니다.
 3) 입력값·프리셋·설정은 같은 폴더의 data 폴더에 자동 저장됩니다.
    폴더째로 보관/이동하세요. (exe만 떼면 데이터를 못 찾습니다.)


------------------------------------------------------------
 2. 공통 조작
------------------------------------------------------------

 - 뒤로 (왼쪽 위)        : 이전 화면으로.
 - 메인으로 (오른쪽 위)  : 홈 화면으로 바로 이동.
 - 톱니바퀴 (홈 오른쪽 위): 공용 설정으로 이동.
 - 저장 : 바뀐 내용이 있을 때만 켜지고, 저장하면 안내가 잠깐 뜹니다.
 - 숫자 칸은 천 단위 쉼표가 자동으로 붙습니다.


------------------------------------------------------------
 3. 기본 사용 흐름
------------------------------------------------------------

추천을 받으려면 다음 순서로 진행합니다.
  (1) 내 스탯 입력  ->  (2) 내 큐브 옵션 입력  ->  (3) 우선 순위 추천 보기


[ (1) 스탯 입력 ]

홈 화면 맨 아래 '스탯 입력' 버튼으로 들어갑니다.
모든 큐브 계산이 이 값을 기준으로 합니다.

 - 게임에 보이는 표시값 그대로 넣습니다.
 - 회색 스탯(방어 관통력 · 공격 대상 수 · 쿨타임 감소 등)은 기본적으로
   비교·추천에서 제외됩니다. 반영하려면 공용 설정의
   '특정 스탯 딜 환산 비율'에서 비율을 정하면 됩니다. (5번 참고)
 - 아래쪽 '예상 데미지'는 참고용입니다.
 - 초기화로 비우고, 저장으로 기록합니다.

 스탯 프리셋 : 화면 위 '프리셋' 줄에서 여러 벌의 스탯을 저장해 둘 수 있습니다.
   - 드롭다운으로 전환, 추가 / 이름변경 / 삭제 가능.


[ (2) 큐브 옵션 입력 ]

홈 -> 큐브 -> 맨 아래 '큐브 옵션 입력' 으로 들어갑니다.
지금 쓰고 있는 큐브 옵션을 부위별로 넣는 곳이고, 우선 순위 추천의 전제입니다.

 - 큐브 프리셋 : 스탯 프리셋과 별개로 큐브 세팅을 프리셋 별로 저장할 수 있습니다
   (추가 / 이름변경 / 삭제). 보스용·일반용처럼 나눠 두기 좋습니다.

 - 장비 부위 버튼(모자 ~ 귀고리)을 누르면 입력 창이 뜹니다.
   윗잠(미라클 큐브) / 아랫잠(에디셔널 큐브) 각각:
     - 등급 선택.
     - 잠재 세 줄의 옵션 선택 (옵션 칸은 글자를 입력해 검색할 수 있습니다).
     - 줄마다 잠금 체크 : 잠근 줄은 우선 순위 추천 시 건드리지 않고 그대로 둡니다
       (이미 잘 뽑은 줄 보존 / 크확 최저치 세팅 등).
     - 천장 스택 : 지금까지 쌓인 천장 스택값을 넣으면, 승급까지 남은 양을
       반영해 승급 기댓값을 더 정확히 계산합니다.
     - 저장으로 반영.


[ (3) 우선 순위 추천 보기 - 핵심 ]

홈 -> 큐브 -> 우선 순위 추천.
입력한 큐브 상태를 바탕으로 부위별 "다음에 돌리면 가장 이득인 목표"를 정리해 줍니다.

 위쪽 조작
   - 윗잠 / 아랫잠 체크 : 추천에 포함할 잠재 선택.
   - 정렬 : 장비 부위를 줄 세우는 기준.
       딜 증가량  - 한 번에 올라가는 딜이 큰 순서.
       등장 확률  - 추천 옵션이 잘 뜨는(적은 큐브로 뜨는) 순서.
       1회 리롤   - 한 번 굴려 기존보다 좋은 게 나올 확률이 높은(쉬운) 순서.
       최종 효율  - 종합 가성비 순서 (기본값, 보통 이걸로 봅니다).
   - 슬라이더 : 각 부위의 목표를 얼마나 높게 잡을지.
       왼쪽이 쉬운 개선, 오른쪽이 종결(최고 목표).

 부위 박스 읽는 법
   - 제목 : 부위와 잠재 종류. 승급 추천이면 "에픽 -> 유니크"처럼
     현재 등급 -> 목표 등급(등급별 색)이 함께 표시됩니다.
   - 왼쪽(기존) / 오른쪽(추천) : 현재 옵션과 추천 옵션을 나란히 비교.
     바뀌는 줄 앞에는 삼각형 표시, 잠근 줄에는 빨간 (잠금)이 붙습니다.
     각 칸 표시:
       딜 증가량 / 동일 옵션 등장 확률 총합 / 동일 옵션 큐브 기댓값 / 효율.
     승급 추천이면 확률·기대 큐브 값에 "(승급 기댓값 반영)"이 붙습니다
       (승급에 드는 큐브까지 포함).
   - 오른쪽 위 작은 박스 : 한 번 굴렸을 때의 확률 (한 단계 승급 가능성까지 반영).
       1회 리롤 시 기존 옵션보다 좋은 옵션이 등장할 확률
       1회 리롤 시 추천 옵션보다 좋은 옵션이 등장할 확률
   - 아래 가운데 : 딜 증가량 차이(추천 - 기존)와 최종 효율.

 * 추천 화면에서 창을 키우면 그 크기를 프로그램을 끌 때까지 기억합니다
   (끄면 기본 크기로 돌아갑니다).


[ 추천 다듬기 - 추천 옵션 수치 범위 ]

큐브 옵션 입력 화면 맨 아래 '추천 옵션 수치 범위' 버튼으로 들어갑니다.
"이 스탯은 이 범위를 넘지 않게 추천" 같은 제약을 겁니다
(크리티컬 확률 · 공격 속도 · 계산 불가 스탯처럼 사람마다 효율이 다르거나 효율이 점차 떨어지는 옵션에 유용).

 - 스탯마다 체크를 켜야 범위 제약이 걸립니다.
 - 숫자는 현재값 기준의 증감입니다. 왼쪽이 하한, 오른쪽이 상한이고
   오른쪽이 왼쪽보다 크거나 같아야 합니다.
   예: -10 ~ -5 (현재 100 -> 추천은 90~95만 제안).
 - 칸 옆 '제한없음'을 켜면 그쪽은 한계가 없습니다 (-무한대 / +무한대).
 - 이 설정은 현재 선택된 큐브 프리셋에만 저장됩니다.


------------------------------------------------------------
 4. 그 밖의 큐브 기능
------------------------------------------------------------

추천 외에 직접 따져 보고 싶을 때 쓰는 보조 기능입니다.

 큐브 옵션 비교
   - 왼쪽 / 오른쪽 각각 부위·등급을 고르고 잠재 세 줄을 선택한 뒤
     '비교' 버튼을 누르면 양쪽 효율을 비교합니다.
   - 효율 = 등장 확률 x 딜 증가량 점수 (큐브 1개당 기대 딜 증가량, 클수록 좋음).

 큐브 기댓값
   - 부위 · 등급 · 정렬을 고르면 그 조건에서 나올 수 있는 옵션이 표로 나옵니다.
   - 표 항목: 옵션 이름, 딜 증가량, 등장 확률, 큐브 기댓값
     (그 옵션이 한 줄이라도 뜰 때까지 평균 큐브 수), 효율.
   - 별표(*) = 특수 옵션, '계산 불가' = 아직 데미지로 환산하지 않는 옵션
     (방어 관통력 · 대상 수 · 쿨타임 감소 등).


------------------------------------------------------------
 5. 공용 설정 (톱니바퀴)
------------------------------------------------------------

모든 프리셋에 공통으로 적용됩니다.

 특정 스탯 딜 환산 비율
   - 기본적으로 계산하지 않는 스탯(방어 관통력 · 대상 수 · 쿨타임 감소 등)이나
     사람마다 효율이 다른 스탯 (n차 스킬 레벨) 등을 1단위당 딜 증가율로 직접 환산해
     비교·추천에 반영합니다.
   - 스탯마다 체크를 켜고 값을 넣습니다.
     예: 방어 관통력에 0.5 -> 방관 1%당 딜 +0.5%로 계산.
   - 체크를 끄면 기본 처리로 돌아갑니다 (값이 남아 있어도 무시).

 폰트
   - 전체 글자 크기를 50% / 100% / 150% / 200% 중에서 고릅니다.

 창 크기
   - 고정 비율(%) : 화면별 기준 크기를 비율로 키우거나 줄입니다.
   - 픽셀 직접 입력 : 창 가로·세로를 직접 지정합니다.
     내용이 잘리면 스크롤바로 볼 수 있습니다.


------------------------------------------------------------
 6. 용어 설명
------------------------------------------------------------

 - 윗잠 / 아랫잠 : 잠재능력(미라클 큐브) / 에디셔널 잠재능력(에디셔널 큐브).
     아랫잠은 큐브 가격이 2배라 효율·정렬에 반영됩니다.
 - 승급(등급업) : 큐브를 굴리다 등급이 한 단계 오르는 것. 일정 개수를 쓰면
     강제 승급됩니다. 천장 스택은 승급까지 얼마나 쌓였는지입니다.
 - 딜 증가량 : 그 옵션 구성이 현재 대비 딜을 몇 % 올리는지.
 - 딜 증가량 차이 : 추천 딜 증가량 - 기존 딜 증가량.
 - 등장 확률 : 한 큐브에 그 옵션이 나올 확률.
 - 동일 옵션 등장 확률 총합 : 줄 순서가 달라도 같은 옵션 묶음이 나오는
     모든 경우를 합한 확률.
 - (동일 옵션) 큐브 기댓값 : 그 옵션이 나올 때까지 평균적으로 필요한 큐브 수
     (= 1 / 확률). 승급 추천이면 승급에 드는 큐브까지 포함합니다.
 - 효율 : 등장 확률 x 딜 증가량 점수. 큐브 1개당 기대 딜 증가량.
 - 최종 효율 : 딜 증가량 차이 x 등장 확률 / 큐브 가격.
     부위 우선순위를 정하는 종합 지표.
 - 1회 리롤 확률 : 큐브를 한 번 굴렸을 때 더 좋은 옵션이 나올 확률
     (한 단계 승급 가능성까지 반영).
 - 회색 스탯 : 데미지로 환산하지 않는 스탯.
     딜 환산 비율을 정하면 반영됩니다.
 - 표시되는 확률·기대 큐브 수는 평균값입니다.
