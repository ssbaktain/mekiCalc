스탯 입력 가이드

계산이 정확하려면 게임의 스탯 창 값을 MekiCalc 프리셋 > 캐릭터에 제대로 옮겨 적어야 합니다. 특히 유물을 해제한 값으로 넣는 것이 중요합니다(유물은 별도로 조립되므로, 유물이 낀 값을 넣으면 이중 계산됩니다). 아래 순서대로 따라 하면 됩니다.

핵심 요약 — ① 게임에서 유물을 모두 해제한 상태로 예상 능력치(스탯 정보 창)를 연다. ② 공격력·주스탯은 옆의 ⓘ를 눌러 + 수치와 % 수치를 따로 넣는다. ③ 나머지 스탯은 창에 보이는 값을 그대로 같은 이름 칸에 옮겨 적는다.

1단계 — 게임에서 프리셋 열기

게임 화면 우측 상단의 햄버거 버튼( 모양)을 누른 뒤, 아래의 프리셋 메뉴로 들어갑니다.

2단계 — 유물을 모두 해제하기

유물 프리셋에서 유물 슬롯이 모두 빈(＋) 상태인 프리셋을 선택하거나 새로 만들어 적용합니다. 이렇게 유물을 뺀 상태여야 스탯 창에 유물 효과가 섞이지 않습니다. (MekiCalc에서는 유물을 프리셋 > 유물에서 따로 입력하므로, 캐릭터 스탯에는 유물이 빠진 순수 스탯만 넣습니다.)

3단계 — 예상 능력치(스탯 창) 열기

유물을 해제한 상태에서 예상 능력치 버튼을 눌러 스탯 창을 엽니다. 여기 표시되는 값이 옮겨 적을 대상입니다.

4단계 — 스탯 정보 창 살펴보기

예상 능력치를 누르면 아래처럼 스탯 정보 창이 열립니다. 여기서 두 가지 방식으로 옮겨 적습니다.

  • 공격력·주스탯(그림의 LUK 등)은 옆에 ⓘ가 있습니다. ⓘ를 눌러 + 수치와 % 수치를 따로 확인해 각각 넣습니다(아래 5·6단계).
  • 그 밖의 스탯(크리티컬 확률·크리티컬 데미지·공격 속도·스탯 비례 데미지·데미지 등)은 창에 보이는 값을 그대로 MekiCalc의 같은 이름 칸에 넣으면 됩니다.

5단계 — 공격력 옮겨 적기

스탯 창에서 공격력 옆의 ⓘ를 누르면 상세 정보가 열립니다.

상세 정보의 현재 보유 중인 능력치에 + 수치와 % 수치가 나뉘어 있습니다. 이 두 값을 MekiCalc의 공격력(+)과 공격력% 칸에 각각 그대로 넣습니다. (합산 값이 아니라 +와 %를 따로 넣는 점에 주의하세요.)

6단계 — 주스탯 옮겨 적기

같은 방식으로 주스탯(직업에 따라 LUK·STR·DEX·INT 중 하나) 옆 ⓘ를 눌러 상세 정보를 엽니다.

+ 수치는 MekiCalc의 주스탯(+), % 수치는 주스탯%에 넣습니다.

정리 — 나머지 스탯

공격력·주스탯 외의 스탯(크리티컬 확률·크리티컬 데미지·데미지%·최소/최대 데미지 배율·공격 속도·최종 데미지 등)은 4단계 스탯 정보 창에 보이는 값을 그대로 MekiCalc의 같은 이름 칸에 옮겨 적으면 됩니다.

자주 하는 실수 — 유물을 낀 상태의 스탯을 넣으면 유물이 두 번 반영되어 딜이 부풀려집니다. 반드시 유물을 해제한 뒤 스탯 창 값을 옮기세요. 스킬 효과로 얻는 능력치는 게임 상세 정보에 포함되지 않으며(스탯 창 안내 문구 참고), MekiCalc이 내부에서 따로 계산하므로 신경 쓰지 않아도 됩니다.
