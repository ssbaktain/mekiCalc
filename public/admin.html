카카오봇 방 관리

방별 권한을 켜고 끕니다. 공지·리마인더는 새 공지·종료 임박 알림 발송, 명령 응답은 방에서 /공지 등 명령에 응답합니다. 방 새로고침을 누르면 봇이 참여한 오픈채팅 방을 자동 인식하며, 새 방은 권한이 모두 꺼진 채 등록됩니다.

방 이름 chatId 공지·리마인더 명령 응답 문의 알림
아직 등록된 방이 없습니다. 방 새로고침을 누르면 봇이 참여한 오픈채팅 방을 자동 인식합니다.
권한을 바꾼 뒤 각 행의 저장을 눌러야 반영됩니다. 문의 알림을 켠 방으로 새 제보/문의가 들어올 때 요약이 전송됩니다(예: 테스트 방). 방 이름은 사이트에서 바꾼 값이 우선이며, 새로고침해도 덮이지 않습니다. 이름을 비우고 저장하면 실제 카톡 방 이름(회색)이 표시됩니다.

디스코드 공지 봇

디스코드 채널의 웹훅 URL을 등록하면 새 공지·종료 임박 안내가 그 채널로 전송됩니다(카톡과 동일 내용). 디스코드에서 채널 설정 → 연동 → 웹후크 → 새 웹후크 → URL 복사로 만든 주소를 붙여넣으세요.
